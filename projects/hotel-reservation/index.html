Hotel Reservation System

A desktop system for booking rooms, finding and editing reservations by reference number, and checking guests out. This web version runs the same screens and validation rules in your browser.

  • Book, update and remove reservations; select a row to load it.
  • Search by reference no. (try HTL-03242024-51228).
  • Click a column header to sort.
  • Check Out saves a receipt as a .txt file.
